# 领域调研与图文导读

## 目标与读者

把分散资料组织成可解释、可追溯的知识结构，并交付图文并茂的内部学习资料。默认读者具备理工科基础，但没有该领域背景；默认用中文，用户指定其他语言时随之调整。

调研终点由调用者指定，例如建立领域认识、比较选型或准备实施。不要默认每次都要设计实验或推荐产品。主题、终点、范围、重点、应用背景和输出要求从当前对话提取，已有信息不再询问。

## 1. 预检索与范围确认

- 先检查用户提供的资料与现有项目文献，再通过可用检索工具核查外部来源。宽泛主题先识别术语、主要分支、相邻概念和代表性来源。
- 向用户展示简洁的领域地图与建议目录，说明各章解决什么问题、建议深入哪些路线。不要把待核实的初步分类写成定论。
- 若调用未给出终点，在展示预检索结果时一起询问；范围、目录、终点及实质性的资源约束集中在同一轮讨论。
- 等待用户确认宽泛主题的方向后深入。用户已给出清晰范围、终点或认可目录时沿用，不重复设置审批点。
- 目录确认后自主搜集、写作、配图与检查。小节调整、补充来源和换图直接推进；显著扩大范围、影响终点的证据缺口、付费或其他额外投入再集中讨论。可继续完成不依赖这些决策的部分。

## 2. 按知识覆盖深入搜集

建立轻量来源表，记录题名、作者/机构、年份、链接/DOI、本地原文及实际阅读依据。根据主题选用资料：

- 百科、教材、课程和综述用于术语、分类与整体框架。
- 原始论文支撑具体方法贡献、实验结果和性能比较。
- 官方文档、标准和厂商资料说明设备参数、工程条件及实现细节；注明版本、日期与测试条件，并辨别厂商自述。
- 博客及讨论提供直观解释与检索线索，关键说法再交叉核对。

优先追踪代表性工作的原始来源。用核心术语、别名及中英文检索词补足覆盖，必要时追踪参考文献和后续研究。区分经典基础与近期进展，时间敏感结论按当前来源核查。

边搜集边搭建讲解。主要路线能够解释原理、代表工作、适用条件和差异，关键说法有依据且关键图片已找到，即进入完整写作；写作发现缺口后定向补查。不要用固定篇数、图片数或篇幅代替覆盖判断。

原文不可得时查找合法可用的作者稿、机构版本或公开页面，记录获取状态。摘要只能支撑其实际包含的信息。来源分歧应核对对象、定义、工况和日期，并说明仍未解决的差异。

## 3. 以解释逻辑组织正文

共同骨架为：问题与基本概念 → 原理与方法分类 → 发展脉络及代表工作 → 方法比较与适用条件 → 前沿问题 → 与调研终点对应的综合讨论。按主题调整章节，历史可以穿插在方法解释中。

- 先建立通用概念及方法关系，再过渡到具体对象。领域级调研的项目应用通常放在末章，避免让应用场景支配前面的学科介绍。
- 用较为书面的解释性语言连接论点、依据和含义；每段承担明确的讲解任务。首次出现术语解释含义，公式交代变量、物理意义与使用条件，必要时补充数值例子。
- 沿问题或技术路线整合来源，避免逐篇摘要拼接。选型比较写清比较维度和工况；实施终点才加入相应资源、步骤与验证方案。
- 图文导读服务于学习，不套用投稿式贡献宣称、审稿人模拟或固定摘要格式。
- 直接说明方法能做什么及适用条件，删除重复免责声明。保留影响理解的模型假设、证据范围和不确定性，集中放在相关方法或讨论处。
- 区分来源报告的结果、跨来源综合判断和拟议方案。教学算例及自绘示意明确标注，数值、机制和优势均应有依据。

## 4. 让图片参与讲解

按解释任务选择原理图、装置图、流程图、代表结果及路线对比图，不设固定图数。优先使用能够实际核读的参考资料原图；缺少适合的图时补绘教学示意。

每组图解释“展示什么、怎么看、支持什么结论”，并注明作者/机构、年份、原图号、页码或网页位置及来源链接。区分数值仿真、实验数据与教学示意；不同材料、实验阶段及观测量不混用。

从 PDF 提取图时检查完整坐标、色标、图例与分图标签，核对图注及相关正文。保留足够分辨率，放大后可读。不得靠猜测标注图号或数据含义。详细图源记录和交付检查见 [delivery.md](references/delivery.md)。

## 5. 交付与完成标准

默认交付可编辑 Markdown、支持目录导航与图片放大的离线 HTML、参考文献与图片来源索引，以及取得的原文或网页来源记录。保存位置遵循用户选择及当前项目结构，复用已有原文，避免重复堆放。PDF、Word、PPT 按用户要求另行生成。

可使用 [build_reader.mjs](scripts/build_reader.mjs) 将正文及本地图片生成自包含阅读版；先读 [delivery.md](references/delivery.md) 的依赖与使用方法。该工具是可选辅助，已有阅读版可继续维护。

交付前检查并修正：

1. 讲解覆盖主要概念、方法关系与差异，达到调用者指定终点。
2. 关键结论可追溯；比较注明条件；原文结果、综合判断及建议清楚区分。
3. 图片清晰完整，图文一致；引用和本地链接有效；实际渲染检查通过。
4. 表达连贯、书面且可读，避免术语堆积和重复设限。

保存有用的来源与复现信息即可，不为每次任务生成庞大的审计体系。最终给出阅读版、可编辑正文入口及影响使用的重要未决问题。
