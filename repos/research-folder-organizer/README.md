# Research Folder Organizer

Organize research materials locally around the question they answer, preserving existing project structure and raw inputs. Routine work updates affected README navigation without requiring inventories, task registries, or a separate Wiki.

## Entry points

- [Skill instructions](research-folder-organizer/SKILL.md): default local workflow and authorization boundaries.
- [Full restructuring](research-folder-organizer/references/full-restructure.md): optional project-wide workflow when requested.
- [Inventory helper](research-folder-organizer/scripts/inventory.py): optional full inventory reports; no source moves.

Inputs are the requested task area and existing project conventions. Outputs are organized task materials and updated navigation. Install through the collection's installer; see the [collection README](../../README.md).
